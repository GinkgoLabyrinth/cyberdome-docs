# cyberdome-docs

Публичные рабочие схемы CYBERDOME для бригад: чертежи, раскрой, перечни работ.

**Репозиторий открыт всем.** Сюда — только техническое: без имён клиентов, адресов и деревень, цен, телефонов. Объекты называем по модели и номеру (`m9/`). Всё рабочее (клиенты, подрядчики, деньги) — в закрытом `GinkgoLabyrinth/cyberdome`.
